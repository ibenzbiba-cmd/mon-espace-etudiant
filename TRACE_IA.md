# TRACE IA 

## 1. Prompt initial

Crée un mini-site étudiant en HTML, CSS et JavaScript.
Il doit contenir un titre, trois modules de cours et un bouton interactif.

## 2. Prompt amélioré

Agis comme un développeur web spécialisé en HTML, CSS et JavaScript.

Je suis étudiante en première année informatique et je réalise un projet intitulé Mon espace étudiant.

Crée un mini-site moderne et responsive contenant :

- Un titre principal.

- Trois cartes représentant mes modules.

- Un bouton qui affiche et cache un message.

Utilise un code simple, bien organisé et facile à comprendre.

Sépare le HTML, le CSS et le JavaScript en trois fichiers.

Explique le rôle de chaque partie du code.
