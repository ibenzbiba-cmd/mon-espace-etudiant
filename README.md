# Mon espace étudiant

## Présentation
Ce projet est un mini-site web réalisé dans le cadre du module Digital Skills 1.

Il permet de présenter mes différents modules universitaires.

## Technologies utilisées
- HTML
- CSS
- JavaScript

## Organisation des fichiers
- index.html : Page principale
- assets/css/style.css : Mise en forme 
- assets/js/app.js : Interaction JavaScript

## Lancer le projet
Ouvrir index.html avec l'extension Live Server dans Visual Studio Code.
